# Oakbase Website Mock

Static GitHub Pages mock for the future Oakbase website.

The current narrative focuses on the sharper commercial offer:

- Digital workforce design and operations.
- Start with one operational bottleneck.
- Build AI agents around real business work.
- Operate them through a private Oakbase Workspace.
- Measure value through jobs completed, hours released and bottlenecks removed.

Visual direction:

- Apple-inspired product page.
- Light interface, generous spacing and minimal navigation.
- Large centered hero with a rendered Oakbase Workspace product visual.
