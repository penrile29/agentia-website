# Firm knowledge website assets

These files preserve the assets used in the approved Oakbase website prototype. No brand artwork has been altered.

- `teams.svg`, `calendar.svg`, `whatsapp.svg`, `gmail.svg`, `slack.svg`, and `salesforce.svg`: [gilbarbara/logos](https://github.com/gilbarbara/logos), distributed under CC0. See `LICENSE-gilbarbara-logos`.
- `outlook.svg`, `onenote.svg`, and `copilot.svg`: [homarr-labs/dashboard-icons](https://github.com/homarr-labs/dashboard-icons), distributed under Apache-2.0. See `LICENSE-dashboard-icons`.
- `claude.svg` and `chatgpt.svg`: [@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons), package version 1.95.1, distributed under MIT. See `LICENSE-lobehub-icons`.
- `hubspot.svg`, `clio.svg`, and `dynamics.svg`: decoded without modification from the approved prototype's embedded SVG assets.
- `lucide-0.468.0.min.js`: [Lucide](https://lucide.dev), pinned to version 0.468.0, UMD distribution. See `LICENSE-lucide`.
- `dm-sans-latin-1.woff2`: DM Sans, Latin variable font served by Google Fonts. `dm-sans.css` declares the 400, 500, and 600 weights used by the site. See `OFL-DM-Sans.txt`.
